
# MNIST Neural Network Digit Recognizer (Deep Learning & AI — Week 1)

A full-stack deep learning application featuring a Dense Neural Network trained on the MNIST handwritten digit dataset using TensorFlow/Keras, served via a FastAPI inference backend, and integrated with an interactive real-time HTML5 drawing canvas UI[cite: 36].

---

## 📌 Features

- **Deep Neural Network:** Trained on 60,000 MNIST training images with `Relu` and `Softmax` activations achieving >97% test accuracy[cite: 36].
- **FastAPI Real-Time Server:** Async prediction endpoint processing base64 image streams[cite: 36].
- **HTML5 Interactive Canvas:** Real-time handwritten digit drawing interface[cite: 36].
